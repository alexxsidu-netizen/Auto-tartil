Panduan Lengkap

Dari persiapan alat sampai kontrol jarak jauh.

1. Yang perlu disiapkan
  • ESP32 DevKit (ESP-WROOM-32) dan kabel micro USB yang mendukung data, bukan kabel charger saja
  • Laptop/PC untuk upload program pertama kali
  • Untuk suara: HP bekas yang membuka halaman ini, atau modul MAX98357A + speaker 4-8 ohm
  • WiFi rumah yang selalu menyala (untuk kontrol jarak jauh)
2. Install Arduino IDE & board ESP32
  1. Install Arduino IDE di PC.
  2. File → Preferences, isi "Additional boards manager URLs" dengan https://espressif.github.io/arduino-esp32/package_esp32_index.json
  3. Tools → Board → Boards Manager, cari esp32, install "esp32 by Espressif Systems".
  4. Install driver CP2102 kalau port COM tidak muncul.
3. Upload sketch ke ESP32
  1. Colok ESP32 ke PC.
  2. Tools → Board → ESP32 Dev Module, lalu pilih Port yang muncul.
  3. Klik Upload. Kalau macet di "Connecting...", tahan tombol BOOT sampai upload jalan.
  4. Buka Serial Monitor (115200) untuk melihat pesan dari ESP32.
4. Konek lewat WiFi (hotspot ESP32)
  1. Nyalakan ESP32. Cari WiFi AutoTartil di HP (password awal 12345678).
  2. Sambungkan, pilih tetap terhubung walau tanpa internet.
  3. Buka browser: http://192.168.4.1 (pakai http, bukan https).
  4. Di menu WiFi, scan dan pilih WiFi rumah, isi password, tekan Hubungkan.
  5. Catat IP baru ESP32, lalu isi di menu Sistem.
5. Konek lewat Bluetooth
  1. Aktifkan Bluetooth dan Lokasi di HP (Android mewajibkannya untuk scan).
  2. Buka halaman ini di Chrome Android lewat HTTPS (misalnya Cloudflare Pages) atau localhost.
  3. Menu Bluetooth → "Cari & sambungkan ESP32" → pilih perangkat.
  • iPhone/Safari tidak mendukung Web Bluetooth.
  • Halaman yang dibuka dari ESP32 (http) tidak bisa memakai Bluetooth.
6. Kontrol jarak jauh (mode Internet)
  1. ESP32 harus tersambung ke WiFi rumah yang punya internet (Starlink juga bisa).
  2. Buka menu Sistem → Jalur koneksi → Internet (jarak jauh).
  3. Isi Kode rumah (min 8 karakter, acak dan rahasia). Kode yang sama harus ada di sketch ESP32.
  4. Tekan "Sambungkan cloud". Titik di bawah jam berubah hijau kalau berhasil.
  5. Matikan "Putar suara di HP" di menu Tartil, lalu tekan Putar.
  • Broker publik bersifat terbuka. Siapa pun yang tahu kode rumahmu bisa mengontrol, jadi jangan dibagikan.
  • Satelit GPS hanya memancar satu arah, jadi tidak bisa dipakai untuk mengirim perintah.
7. Cara pakai tiap menu
  • Tartil: pilih surah, ayat, qari, jumlah ulang, lalu Putar. Ayat berikutnya diputar otomatis.
  • Jam: zona waktu, format, teks berjalan, dan sinkron waktu.
  • Jadwal: buat alarm tartil harian, lalu kirim ke ESP32.
  • Saklar: nyala/mati Smart Switch, timer otomatis mati, nyala bareng tartil.
  • WiFi: scan jaringan, pilih, isi password, hubungkan.
  • Warna: pilih tema atau atur warna, ukuran, font, glow jam.
  • Sistem: jalur koneksi, IP, kode rumah, simpan atau reset.
8. Uji coba tanpa ESP32
  1. Buka menu Uji Coba → "Aktifkan simulasi ESP32".
  2. Tekan "Jalankan semua tes". ✅ berarti benar, ❌ ada yang salah, ⚠️ peringatan.
  3. Coba juga menu WiFi → Scan (data contoh) dan lihat Log.
9. Kalau ada masalah
  • Port COM tidak muncul: ganti kabel (harus kabel data), install driver CP2102.
  • HP tidak bisa buka 192.168.4.1: pastikan tersambung ke WiFi AutoTartil, matikan data seluler, pakai http://.
  • Halaman HTTPS tidak bisa kontrol lewat WiFi: browser memblokir (mixed content). Pakai mode Internet atau Bluetooth.
  • Cloud tidak terhubung: cek internet HP, kode rumah minimal 8 karakter, dan library MQTT termuat.
  • Audio tidak bunyi: tekan Putar sekali, cek volume media dan internet.

11. Saklar: pilih cara (baca dulu)
  • Saklar "Smart Switch" di fotomu memakai firmware bawaan pabrik. Firmware itu hanya bisa dikontrol lewat aplikasinya (eWeLink / Smart Life), tidak bisa langsung dari halaman ini.
  • Cara A (paling mudah): tetap pakai aplikasinya. Halaman ini tidak dipakai untuk saklar.
  • Cara B (menu Saklar di halaman ini): ganti firmware saklar ke Tasmota (gratis). Butuh membuka casing, adaptor USB-TTL 3.3V (CP2102/FTDI), dan kabel jumper. Tidak semua saklar sejenis bisa, tergantung chip di dalamnya.
  • Cara C (paling aman): pakai ESP32 yang sudah ada + modul relay 1 channel. Pin relay dikontrol dari sketch ESP32 (tanya saya kalau mau dibuatkan sketchnya).
12. Saklar: pasang Tasmota (Cara B)
  1. Cabut saklar dari listrik 220V. Selama flashing, saklar hanya boleh dapat daya 3.3V dari adaptor USB-TTL, tidak boleh ada kabel listrik rumah.
  2. Buka casing. Cari chip ESP8266/ESP8285 dan pin TX, RX, GND, 3V3, serta GPIO0 (biasanya dekat tombol).
  3. Sambung: TX adaptor ke RX saklar, RX adaptor ke TX saklar, GND ke GND, 3V3 ke 3V3. Hubungkan GPIO0 ke GND sebelum adaptor dicolok ke PC (mode flash).
  4. Di PC, buka Chrome atau Edge ke https://tasmota.github.io/install/, pilih Tasmota, tekan Connect, pilih port, lalu Install.
  5. Setelah selesai, lepas GPIO0 dari GND, cabut adaptor, rakit kembali casing.
  • Kalau ada tulisan chip yang tidak dikenali (misalnya modul Tuya/WB2S), jangan dipaksa. Pakai Cara A atau C.
13. Saklar: setting Tasmota & sambungkan ke halaman ini
  1. Pasang saklar ke listrik (setelah casing tertutup rapat). Cari WiFi tasmota-xxxx di HP, sambungkan, buka 192.168.4.1.
  2. Pilih WiFi rumah, isi password, Save. Saklar restart dan dapat IP baru (lihat di router atau aplikasi Fing).
  3. Buka IP itu di browser. Configuration → Configure Module → pilih Sonoff Basic (1) → Save. Kalau relay tidak bunyi saat ditekan tombol Toggle, model saklarmu butuh template lain.
  4. Configuration → Configure MQTT: Host broker.emqx.io, Port 1883, Topic isi kode acak panjang misalnya saklar_x7k29qpm (jangan pakai tulisan yang mudah ditebak), kosongkan User dan Password. Save.
  5. Di halaman ini, menu Saklar: Jalur = Internet (MQTT), isi Topik dengan kode yang sama persis, tekan Sambungkan.
  6. Tekan Cek status. Kalau tulisan berubah dan tombol bulat bisa menyalakan relay, berhasil.
  • Mode WiFi lokal (IP): isi IP saklar. Hanya jalan kalau halaman dibuka lewat http (misalnya dari ESP32 atau file lokal), bukan dari Cloudflare HTTPS.
  • Broker publik terbuka. Siapa pun yang tahu topikmu bisa menyalakan saklar, jadi rahasiakan dan jangan dipakai untuk beban yang berbahaya.
  • Jadwal tanpa halaman terbuka: di halaman Tasmota, Configuration → Configure Timers, aktifkan Timers, atur jam dan hari.
  • Opsi "Nyalakan saklar saat tartil mulai" cocok untuk menyalakan speaker otomatis bersamaan dengan alarm tartil.
