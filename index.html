Belum ada aktivitas
1. Yang perlu disiapkan
  • ESP-WROOM-32 (ESP32 DevKit) dan kabel micro USB yang mendukung data, bukan kabel charger saja
  • Laptop/PC untuk upload program pertama kali
  • Opsional: modul audio MAX98357A dan speaker 4-8 ohm
  • HP Android dengan Chrome
2. Install Arduino IDE & board ESP32
  1. Install Arduino IDE di PC.
  2. Buka File → Preferences, isi "Additional boards manager URLs" dengan https://espressif.github.io/arduino-esp32/package_esp32_index.json
  3. Buka Tools → Board → Boards Manager, cari esp32, install "esp32 by Espressif Systems".
  4. Install driver USB (CP2102 atau CH340) kalau port COM tidak muncul.
3. Upload sketch ke ESP32
  1. Colok ESP32 ke PC.
  2. Tools → Board → pilih ESP32 Dev Module.
  3. Tools → Port → pilih port COM yang muncul.
  4. Klik Upload. Kalau macet di "Connecting...", tahan tombol BOOT di board sampai upload jalan, lalu lepas.
  5. Buka Serial Monitor (115200) untuk melihat pesan dari ESP32.
4. Konek lewat WiFi (hotspot ESP32)
  1. Nyalakan ESP32. Cari WiFi bernama AutoTartil di HP (password awal 12345678).
  2. Sambungkan, pilih tetap terhubung walau tanpa internet.
  3. Buka browser: http://192.168.4.1 (pakai http, bukan https).
  4. Di menu WiFi, scan dan pilih WiFi rumah, isi password, tekan Hubungkan.
  5. Catat IP baru ESP32, lalu isi di menu Sistem.
5. Konek lewat Bluetooth
  1. Aktifkan Bluetooth di HP (dan Lokasi, Android mewajibkannya untuk scan).
  2. Buka halaman ini di Chrome Android lewat HTTPS (misalnya hosting Cloudflare Pages) atau localhost.
  3. Menu Bluetooth → "Cari & sambungkan ESP32" → pilih perangkat.
  4. Jalur koneksi otomatis pindah ke Bluetooth. Coba tombol "Status".
  • iPhone/Safari tidak mendukung Web Bluetooth.
  • Halaman yang dibuka dari ESP32 (http) tidak bisa memakai Bluetooth, karena butuh HTTPS.
6. Cara pakai tiap menu
  • Tartil: pilih surah, ayat, qari, jumlah ulang, lalu Putar. Ayat berikutnya diputar otomatis.
  • Jam: pilih zona waktu dan format. "Sinkron dari waktu HP" mengirim jam HP ke ESP32.
  • WiFi: scan jaringan, pilih, isi password, hubungkan.
  • Warna: pilih tema atau atur warna, ukuran, font, glow jam.
  • Jadwal: buat alarm tartil harian, lalu kirim ke ESP32.
  • Sistem: IP ESP32, jalur koneksi, simpan atau reset pengaturan.
7. Uji coba tanpa ESP32 (saat board mati)
  1. Buka menu Uji Coba.
  2. Tekan "Aktifkan simulasi ESP32". Sekarang semua tombol bicara dengan ESP32 virtual di HP.
  3. Tekan "Jalankan semua tes". Tanda ✅ berarti benar, ❌ berarti ada yang salah (alasannya tertulis).
  4. Coba juga menu WiFi → Scan (data contoh) dan lihat Log untuk memastikan perintah terkirim.
  5. Tes "Koneksi ESP32" akan bertanda ⚠️ selama simulasi, karena itu bukan board asli.
8. Kalau ada masalah
  • Port COM tidak muncul: ganti kabel (harus kabel data), install driver CP2102/CH340.
  • HP tidak bisa buka 192.168.4.1: pastikan tersambung ke WiFi AutoTartil, matikan data seluler sebentar, pakai http://.
  • Halaman HTTPS tidak bisa kontrol lewat WiFi: browser memblokir (mixed content). Buka halaman dari ESP32 atau pakai Bluetooth.
  • Bluetooth tidak muncul: Chrome Android, Bluetooth dan Lokasi aktif, sketch sudah mengiklankan service UUID, atau centang "Tampilkan semua perangkat".
  • Audio tidak bunyi: tekan Putar sekali, cek volume media dan internet. Tes "Audio online" di menu Uji Coba membantu.
  • Ada tes ❌: baca pesannya dan buka Log di menu Uji Coba.
